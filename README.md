# Maha Alamri

Personal portfolio. One self-contained `index.html`; everything (retrieval, neural network, simulations) runs in the browser.

**Live:** https://m40aha.github.io

## Publish on GitHub Pages
1. Create a public repository named `M40aha.github.io`.
2. Upload `index.html` and this `README.md` to the root.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `root` → Save.
4. Open https://m40aha.github.io after a minute or two.
